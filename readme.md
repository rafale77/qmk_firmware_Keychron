# Keychron QMK Firmware

This fork from the Keychron repo is not meant to contribute to the parent but I am happy to share my own personalizations.

A few differences on my fork:
1. Use of the latest Chibios updates
2. Only supports the two QMK keyboards I own: The Lemokey P3 HE and the Aaru TKL which has gone stale for many years. (Yes it isn't a Keychron Keyboard)
3. Added ability to add a background color to the "wide" and "splash animations which can also be controlled in Via. Added the Via keyboard definition for both.
